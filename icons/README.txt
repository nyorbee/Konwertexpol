konwertexpol.ico  - the application icon: shown at the Konwertexpol entry in the right-click menu and in the title bar of the windows.
logo.png          - the logo shown at the bottom of every window (a click opens the author's page).
Optional icons for single menu entries - drop .ico files here with these names, then run install.bat again:
compress.ico, resize.ico, trim.ico, unlock.ico, join.ico, extract.ico, pages.ico, merge.ico, convert.ico, meta.ico,
mp3.ico, jpg.ico, png.ico, pdf.ico ... (an entry with an icon file of the format's name shows it, e.g. mp4.ico).
